# Colemak-DH ZXCV Android layout

This fork builds an Android physical keyboard layout APK with an extra layout named:

```text
Colemak Mod-DH ZXCV US
```

The layout maps physical QWERTY scancodes directly to Colemak-DH while keeping `Z` on the normal physical `Z` key, instead of using the ISO angle-mod position:

```text
Q W F P B J L U Y ;
A R S T G M N E I O '
Z X C D V K H , . /
```

GitHub Actions builds a debug APK and uploads it as the `colemak-dh-zxcv-debug-apk` artifact.
